# Dashboard Guide & Interpretation

## 1. Box Plot
Shows the spread of prices across categories. The median, quartiles and potential outliers help understand variation.

## 2. Violin Plot
Shows the distribution shape of prices. Wider areas represent values with greater density.

## 3. Correlation Heatmap
Shows relationships between numerical variables. Values close to +1 indicate strong positive association, while values close to -1 indicate strong negative association.

## 4. Sales Trend
The Plotly line chart allows users to hover over points and inspect exact sales values.

## 5. Product Performance
The interactive bar chart compares total sales by product and provides hover details.

## 6. Sales Distribution
The interactive pie chart shows the contribution of each available region/category grouping to total sales.

## Dashboard Best Practices Used
- Consistent visual theme
- Clear titles
- Readable labels
- Appropriate chart types
- Interactive hover information
- Separate visualization output folder
- Reproducible Python script
