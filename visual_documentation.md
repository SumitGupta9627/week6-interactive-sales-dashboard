# Visual Documentation

The `visualizations/` folder contains the screenshots and interactive charts generated by the dashboard.

## Static Visual Evidence
- `boxplot.png` — product-wise sales distribution.
- `violinplot.png` — product-wise sales density.
- `correlation_heatmap.png` — numerical correlation matrix.
- `dashboard_overview.png` — 2×2 dashboard overview.

## Interactive Visual Evidence
- `sales_trend_interactive.html` — interactive sales trend.
- `product_performance_interactive.html` — interactive product performance.
- `sales_distribution_interactive.html` — interactive sales distribution.
- `customer_segmentation_interactive.html` — interactive customer segmentation.

## Working Application Evidence
`dashboard_demo.gif` provides a visual demonstration of the completed dashboard workflow.
