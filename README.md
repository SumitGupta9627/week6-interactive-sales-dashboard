# Interactive Sales Dashboard

## Week 6 - Data Visualization Mastery with Seaborn

An interactive sales dashboard developed using Python, Seaborn, Matplotlib and Plotly. The project provides statistical visualizations, sales analysis, product performance analysis and an overview dashboard.

## Features

- Sales trend visualization
- Product performance analysis
- Sales distribution visualization
- Box plot
- Violin plot
- Correlation heatmap
- Interactive Plotly charts
- Customer segmentation documentation
- Professional 2×2 dashboard overview
- Dashboard demonstration GIF

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Dataset

The project uses `sales_data.csv`.

Dataset details:

- 100 records
- 7 columns
- Date
- Product
- Quantity
- Price
- Customer_ID
- Region
- Total_Sales
